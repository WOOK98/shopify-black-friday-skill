# Search-oriented project naming

**Repository:** `shopify-black-friday-skill`

**Chinese display title:** Shopify Black Friday Skill｜BFCM 活动页与自动恢复

The name describes the platform, seasonal intent and artifact type. README language includes Black Friday, Cyber Monday, BFCM, Shopify campaign, newsletter coupon, scheduled restoration and annual reuse where those terms describe implemented behavior. It omits a year so the project remains reusable.

This is qualitative intent-based naming, not a keyword-volume study. No search-volume, ranking or sales improvement claim is made. A point-in-time exact-name search did not surface an exact match; that is not a uniqueness or trademark guarantee.

Official terminology reference: [Shopify BFCM workflow examples](https://www.shopify.com/enterprise/blog/shopify-flow-templates-for-black-friday). The project is independent of Shopify and does not claim to implement Shopify Flow.
